# react-resizable-panels — Layout Rules

Use only for interfaces where user-adjustable panes improve workflow, especially Medication Review.

## Rules
- Preserve a sensible default layout (approximately 60/40 where specified by the approved design).
- Set practical minimum panel sizes.
- Do not use resizable panels for simple card layouts.
- Ensure the screen remains usable without requiring resize interaction.
- Keep responsive/mobile behavior independent from desktop split-pane behavior.

Do not introduce custom drag/resize implementations while this dependency already exists.
