# React Router — Routing Rules

Use the installed React Router for application navigation.

## Rules
- Route definitions belong in the app routing layer.
- Feature code should not construct unrelated route maps.
- Keep route paths stable and descriptive.
- Use route parameters for selected entity IDs where appropriate.
- Do not put domain/business logic in routing components.
- Avoid adding another routing library.

When placeholders become real screens, replace them incrementally rather than rebuilding routing.
